# 💻 Portfólio Pessoal — Charles Donato Rocha

Bem-vindo ao meu portfólio! Este projeto foi desenvolvido com o objetivo de apresentar minha trajetória, meus conhecimentos e projetos na área de tecnologia.

Atualmente, sou estudante de **Análise e Desenvolvimento de Sistemas** e estou em transição de carreira para a área de tecnologia, buscando evoluir constantemente como desenvolvedor.

## 🚀 Sobre o projeto

O portfólio foi criado para reunir minhas informações profissionais, apresentar minhas habilidades e compartilhar projetos desenvolvidos durante minha jornada de aprendizado em programação.

A proposta é construir uma presença profissional na internet e facilitar o contato com recrutadores e profissionais da área de tecnologia.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📂 Funcionalidades

- Apresentação pessoal.
- Seção de habilidades e conhecimentos.
- Exibição de projetos.
- Links para redes profissionais.
- Layout voltado para apresentação profissional.
